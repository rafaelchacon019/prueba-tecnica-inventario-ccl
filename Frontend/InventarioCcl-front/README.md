# InventarioCcl Frontend

Frontend Angular 19 para la prueba tecnica de inventario.

## Ejecucion local

```bash
npm install
npx ng serve
```

La aplicacion queda disponible en:

```text
http://localhost:4200
```

## Build

```bash
npx ng build
```

Para instrucciones completas del proyecto, revisar el `README.md` de la raiz del repositorio.
